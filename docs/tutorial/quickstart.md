# 빠른 시작

IDL 파일 하나를 준비하고, 득팩으로 **C# 코드를 생성**까지 해보는 최소 단계입니다.

---

## 1. 준비

- [득팩 코어·엔진](../products/core-engine/) 빌드/설치가 되어 있어야 합니다.
- 프로젝트 루트 또는 작업 폴더에 `.deuk` 또는 `.thrift` 파일이 하나 있으면 됩니다.

## 2. 실행

프로젝트에서 사용하는 빌드 스크립트에 따라 다릅니다. 일반적으로:

- **Node 스크립트**: `node build-deukpack.js` 또는 프로젝트에서 정한 명령
- **빌드 결과**: 지정한 출력 폴더에 C#/C++ 등 생성 코드와 스키마 JSON이 생성됩니다.

## 3. 다음 단계

- 생성된 코드를 솔루션에 포함하고, [프로토콜](../products/protocol/) 문서를 참고해 직렬화·메시지 처리를 연결합니다.
- Excel 메타를 쓰는 경우 [Excel 애드인](../products/excel-addin/), Unity 연동은 [파이프라인·Unity](../products/pipeline-unity/)를 참고하세요.
