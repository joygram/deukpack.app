# DeukPack 소개

DeukPack은 데이터 정의를 서버, 클라이언트, 기획 도구와 연결하는 개발 도구 제품군입니다. 기존 스키마를 활용하고 필요한 코드와 직렬화 규약을 생성해, 여러 팀이 같은 데이터 계약을 기준으로 작업할 수 있도록 돕습니다.

## 제품이 다루는 영역

- **스키마와 코드 생성:** .deuk와 기존 IDL, OpenAPI 등의 정의를 개발 흐름에 연결합니다.
- **프로토콜과 실행 환경:** 서버와 Unity 클라이언트에서 쓰는 직렬화 및 메시지 규약을 제공합니다.
- **메타 데이터와 파이프라인:** 테이블·스프레드시트 작업을 코드 생성과 검증 과정에 연결합니다.

## DeukPack 팀

우리는 데이터 정의와 연동 작업이 여러 프로젝트에서 반복되는 문제에 주목하는 스타트업 팀입니다. 서버, 클라이언트, 기획 도구가 서로 다른 방식으로 같은 데이터를 표현할 때 생기는 부담을 줄이는 것이 목표입니다.

제품을 만들 때는 기존 기술을 한 번에 교체하도록 요구하기보다, 팀이 이미 가진 스키마와 작업 흐름에서 시작할 수 있는 경로를 우선합니다. 무료 코어와 기술 문서를 공개해 직접 검토하고 적용 범위를 판단할 수 있도록 하고 있습니다.
