# About DeukPack

DeukPack is a family of developer tools that connects data definitions to servers, clients, and planning tools. It helps teams work from a shared data contract by using existing schemas and generating the code and serialization rules they need.

## What the product covers

- **Schemas and code generation:** Bring .deuk, existing IDLs, OpenAPI, and other definitions into the development workflow.
- **Protocols and runtimes:** Share serialization and messaging contracts across servers and Unity clients.
- **Metadata and pipelines:** Connect tables and spreadsheet workflows to code generation and validation.

## The DeukPack team

We are a startup team focused on the data definition and integration work that recurs across projects. Our goal is to reduce the effort caused when servers, clients, and planning tools represent the same data in different ways.

We start with the schemas and workflows teams already have, so they can adopt the tools at a practical pace. The free core and technical documentation are available for teams to evaluate directly.
