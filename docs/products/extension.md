# 확장 제품군

득팩 **코어 위에 붙는 부가 제품**입니다. 기본 4대 제품군(코어·엔진, 프로토콜, Excel 애드인, 파이프라인·Unity)을 확장하는 옵션입니다.

---

## 확장 예시

| 영역 | 내용 |
|------|------|
| **EF** | Entity Framework Core와 연동. DB 스키마·마이그레이션 연동. |
| **DB 마이그레이터** | 득팩 데이터·메타를 DB(SQLite, SQL, NoSQL, Firebase 등)로 업로드·동기화. |
| **Google Sheets** | Excel 애드인과 유사한 스키마 기반 편집·검증을 Google 스프레드시트에서 제공(계획). |
| **Unreal / Elixir** | Unreal 엔진·Elixir 등 추가 플랫폼/언어 지원. |
| **플러그인** | Unity 스토어 등에서 배포하는 스키마 에디터·파이프라인 연동 플러그인. |
