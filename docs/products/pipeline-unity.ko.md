# 득팩 파이프라인·Unity

**한 줄**: **정의·메타 산출물**을 실제 프로젝트·Unity·서버에 연결하는 적용 제품군입니다. 코드·스키마·테이블을 빌드·복사·적용해 Unity·서버에서 검증·로드하며, **서버 연동·실시간 게임 연동**까지 동일 스키마·프로토콜로 이어질 수 있습니다.

## 무엇을 얻을 수 있나요

- **한 번에 연동**: 정의·메타 수정 → 득팩 코드젠 → 산출물 Unity·서버 반영 → 에셋이 스키마·C# 둘 다 참조하는 흐름을 한 파이프라인으로 구성할 수 있습니다. **서버 연동·실시간 게임 연동**에서도 동일 생성 타입·스키마를 사용할 수 있습니다.
- **검증·로드**: 생성된 C# 타입과 스키마 JSON으로 CSV/JSON 검증, 런타임에 테이블·메타 로드.

---

## 제공 기능

| 구분 | 내용 |
|------|------|
| **빌드·복사** | IDL/Excel → 코드젠·스키마·테이블 산출물을 지정 경로에 빌드·복사. |
| **Unity 적용** | 산출물을 Unity 프로젝트 경로에 반영. 에셋·스크립트 참조 갱신. |
| **검증** | 스키마·CSV/JSON 검증으로 데이터 일관성 확인. |
| **로드** | 생성된 C# 타입으로 런타임에 메타·테이블 로드. |

코어 언어 설계·Excel 편집 UI·프로토콜 정책 전체는 각각 [코어·엔진](core-engine.ko.md), [Excel 애드인](excel-addin.ko.md), [프로토콜](protocol.ko.md)에서 다룹니다.
