# 득팩 Excel 애드인

**배포**: Excel 프로토콜·Excel 애드인은 **득팩 코어(npm)와 별도 배포**입니다. 코어는 IDL·코드젠·Binary/Compact/JSON까지 포함하며, Excel 연동이 필요하면 이 제품을 별도로 이용합니다.

**한 줄**: **스키마 기반 메타 작업**(헤더 생성·검증·스키마 비교·Apply·시트 편집)을 스프레드시트에서 하는 애드인입니다. Excel에서 제공합니다.

---

## 무엇을 얻을 수 있나요

- **스키마 일치**: IDL/코드젠에서 만든 스키마를 기준으로 Excel 시트 헤더·타입·검증을 맞출 수 있습니다.
- **기획·밸런스 메타 연동**: 게임 메타·기획 테이블을 Excel에서 편집하고, 동일 스키마로 빌드·Unity·서버와 연동할 수 있습니다.
- **단일 키·복합키**: 테이블 단일 키(tuid 등)·복합키(cid, level 등) 시트 구성을 지원합니다.

---

## 제공 기능

| 구분 | 내용 |
|------|------|
| **헤더 생성** | 스키마 기준으로 시트 헤더(필드명·타입) 자동 생성. |
| **검증** | 시트 데이터가 스키마(타입·필수·기본값)에 맞는지 검증. |
| **스키마 비교** | 기존 시트와 최신 스키마 차이 비교. |
| **Apply** | 스키마 변경 사항을 시트에 반영. |
| **시트 기반 메타 편집** | 시트 단위로 메타 데이터 편집·저장. |

코어 코드젠·서버 패킷 처리·Unity 런타임 로드는 각각 [코어·엔진](core-engine.ko.md), [프로토콜](protocol.ko.md), [파이프라인·Unity](pipeline-unity.ko.md) 제품에서 다룹니다.
