# 득팩 Excel 메타툴 (Schema-Driven Editor)

`득팩 Excel 메타툴`은 게임 기획자와 밸런스 디자이너가 복잡한 데이터를 스키마 기반으로 안전하고 빠르게 관리할 수 있게 돕는 `Excel 전용 생산성 도구`입니다.

<div class="dp-dynamic-notice-product" data-product="excel-addin"></div>

---

## 핵심 가치

### 1. 스키마 기반 헤더 자동 생성
IDL(`*.deuk`)에 정의된 구조를 기반으로 Excel 시트의 헤더를 자동으로 생성하고 동기화합니다.
- **표준 타입 매핑**: 정수, 문자열, 리스트 등을 Excel 칼럼과 직관적으로 매핑합니다.
- **컴팩트 헤더**: 복잡한 계층 구조를 Excel에서 보기 편하도록 최적화된 레이아웃을 지원합니다.

### 2. 강력한 데이터 검증 (Validation)
코드와 데이터 사이의 괴리를 제거하기 위해 입력 단계부터 강력한 검사를 수행합니다.
- **타입 세이프티**: 정수 필드에 문자가 들어오거나 열거형 오타가 발생하는 것을 실시간으로 차단합니다.
- **참조 무결성 (TableLink)**: 다른 테이블의 ID를 참조할 때, 실제 존재하는 값인지 즉시 확인합니다.

### 3. 기획자 친화적 워크플로우
엔지니어의 언어(IDL)를 기획자의 언어(Excel)로 가장 부드럽게 연결합니다.
- **주석 동기화**: IDL의 필드 주석을 Excel 메모로 연동하여 별도 명세서 없이 데이터 의미 파악이 가능합니다.
- **선택 UI**: 필드 타입에 맞는 드롭다운과 선택 팝업을 제공하여 입력 편의성을 높입니다.

---

## 제공 기능 요약

| 구분 | 내용 |
|------|------|
| **헤더 생성** | 스키마 기준으로 시트 헤더(필드명·타입) 자동 생성 및 동기화 |
| **데이터 검증** | 타입, 필수 여부, 범위, 참조(TableLink) 무결성 실시간 검증 |
| **스키마 반영** | 스키마 변경 사항을 기존 데이터 파괴 없이 시트에 안전하게 반영 |
| **통합 빌드** | Excel 데이터를 즉시 바이너리(`*.dpk`) 또는 SQLite DB로 변환 |
