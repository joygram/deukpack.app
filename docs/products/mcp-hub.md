# DeukPackMcp: Universal AI Hub 🚧

!!! warning "Coming Soon"
    This product is currently in **Pre-release / Teaser** stage. It is being tested in closed beta and will be officially released soon.

## Overview

**DeukPackMcp** is a universal MCP (Model Context Protocol) gateway that seamlessly bridges all DeukPack products and external standards (.proto, .deuk, OpenAPI) as real-time **'Skills'** for AI agents.

Instead of giving AI agents just reading manuals, equip them with the **'limbs'** to directly operate and interact with your systems.

---

## Core Values

### 1. Unified Skill Integration (Universal Bridging)
Transform the unique capabilities of each DeukPack product into AI tools.
- **Core · IDL**: Schema analysis and AI semantic context generation.
- **Protocol**: Real-time message tracing and data guardrails.
- **Excel Add-in**: AI agents directly validate and sync planning data in sheets.
- **Navigation**: AI pathfinding queries and NavMesh status inspection.
- **DeukUI**: Design-to-Code conversion via IR (Intermediate Representation) analysis.

### 2. Multi-Protocol Hub
Unify fragmented infrastructure with a single gateway.
- Protobuf (`.proto`)
- Deuk IDL (`.deuk`)
- Thrift (`.thrift`)
- OpenAPI / Swagger
- All aforementioned specs aggregated and served as AI tools from a single MCP server.

### 3. Real-time Unity Bridge
Real-time monitoring and control of Unity engine states by AI.
- High-performance bridging with built-in main-thread safety.
- Manipulation of GameObjects, collection of console logs, and runtime value modification directly by AI.
