# 포지셔닝·타깃

득팩(DeukPack)의 **제품 포지션**과 **타깃**을 요약합니다.

---

## 포지션

- **IDL·코드 생성·직렬화·메타 테이블**을 **한 스택**으로 제공합니다.
- Thrift·Protobuf·OpenAPI·CSV 등 **기존 정의를 그대로** 가져와 **점진적 통합**이 가능합니다.
- **게임·서비스**에서 패킷·메타·기획 테이블·Excel·Unity 연동까지 **한 툴체인**으로 다룰 수 있습니다.

---

## 타깃

| 대상 | 설명 |
|------|------|
| **자체 서버·전용 프로토콜을 쓰는 팀** | Thrift/Protobuf와 메타·테이블·Excel을 함께 쓰고 싶은 경우. |
| **Unity·클라이언트에 메타·테이블을 적용하는 팀** | IDL/Excel → 코드·스키마 → Unity 검증·로드 파이프라인이 필요한 경우. |
| **기존 Thrift/Protobuf/OpenAPI를 유지하면서 확장하고 싶은 팀** | 한 빌드에서 .proto·.thrift·.deuk 혼합 사용으로 점진적 전환. |

상세 타깃·시장 구분은 제품 라인업 문서를 참고하세요.
